SIL'MIR KEYBOARD v5 MEGA
=========================

Что внутри
----------
- кастомная Sil'mir QWERTY для Unexpected Keyboard
- 11 550 слов Sil'mir для подсказок
- 11 550 строк переводческого лексикона
- 12 983 русских семантических алиасов/синонимов
- 58 925 индексированных русских словоформ
- офлайн RU <-> Sil'mir переводчик
- разбор Sil'mir по корню + грамматическим суффиксам
- отдельный слой русской морфологии, синтаксических эвристик и семантики
- поддержка русского текста, русского транслита латиницей и неизвестных заимствований
- никакого интернета для перевода

Главная идея
------------
Sil'mir старается держать одно понятие за одним корнем. Русский так не делает:
одно понятие может выражаться множеством слов, форм и оборотов. Поэтому MEGA
не ищет тупое "русское слово = одна строка словаря".

Цепочка RU -> SIL:
1. точная словоформа
2. грамматический разбор
3. канонический русский смысл / синонимическая семья
4. многословное выражение
5. часть речи и контекст
6. управление предлогом
7. число / падеж / время / лицо / вид
8. сборка формы Sil'mir
9. если понятия нет вообще - фонетическая адаптация в алфавит Sil'mir

Что разбирает русский слой
--------------------------
- существительные: число и основные падежи
- прилагательные: формы рода/числа/падежа сводятся к одному Sil'mir-корню
- наречия: безопасный набор русских наречий -> продуктивный Sil'mir -of
- местоимения: я/ты/он/она/оно/мы/вы/они и частотные падежные формы
- глаголы: настоящее, прошедшее, простое будущее, аналитическое будущее
- частотные совершенные/несовершенные пары и нерегулярные формы
- императив и возвратность там, где форма распознана
- отрицание "не"
- условие "если бы"
- вопросы да/нет и вопросительные слова
- "в/на": различение ГДЕ и КУДА по русской форме и глаголу движения
- "из/от/с": исходное направление
- "к": направление
- наблюдать/смотреть/глядеть "на/за" как объект действия
- два -> двойственное число Sil'mir
- 3+ -> множественное число, без переноса русского родительного управления
- степень: более / самый / слегка / слишком
- усиление: очень / крайне / весьма
- привычное действие: обычно / регулярно / постоянно
- глаголы движения -> sa-/ez- там, где направление выражено лексически
- вынесенный объект вроде "Камень я не вижу"
- несколько предложений с сохранением пунктуации
- русский, набранный латиницей
- многословные семантические алиасы

Защита от тупых синонимов
-------------------------
Если нейтральное русское слово конфликтует со сленговым Sil'mir-корнем,
нейтральный/грамматический корень получает приоритет. Сленговый корень остается
доступен через свое прямое значение, но "идти" больше не обязано превращаться
в "пиздовать" только потому, что словарь однажды решил устроить вечеринку.

Перевод в клавиатуре
--------------------
На клавише P теперь три жеста:

P ↙  = ⇄     AUTO
P ↓  = R→S   принудительно русский -> Sil'mir
P ↘  = S→R   принудительно Sil'mir -> русский

Принудительные режимы нужны для латиницы и смешанных строк, где автоопределение
теоретически может ошибиться.

Если текст выделен - переводится выделение.
Если ничего не выделено - переводится текущая строка перед курсором
(до 2048 символов).

---------
a ↑ æ
e ↑ ə
o ↑ ø
s ↑ ś
z ↑ ź

~ ! @ # $ % ^ & * ( )
` - _ = +
{ } [ ] | \
< > . , ? /
: ; " '

Нужный XML:
Silmir_Unexpected_Keyboard_v5_MEGA.xml

Сборка через GitHub Actions
---------------------------
1. Загрузи содержимое этого архива в корень репозитория, заменив старые файлы.
2. Actions -> Build Silmir Keyboard v5 MEGA.
3. Run workflow.
4. После зеленой сборки скачай Artifact:
   Silmir-Keyboard-v5-MEGA-debug-apk
5. Установи APK.
6. В настройках этой debug-клавиатуры:
   Add an alternate layout -> Custom layout
7. Вставь Silmir_Unexpected_Keyboard_v5_MEGA.xml.

Проверки
--------
- Python reference engine: 45/45 основных RU -> SIL тестов
- Java Android engine: основной контрольный набор совпал с ожидаемыми результатами
- Java SilmirTranslator.java компилируется отдельно javac

Ограничения
-----------
Это офлайн правиловый переводчик, а не большая нейросеть. Он намного умнее
старой версии, но сложные омонимы, длинные вложенные предложения, редкие
идиомы, причастные конструкции и совершенно новые русские слова иногда будут
разбираться эвристически. Если русского понятия нет в базе, оно не исчезает:
используется фонетическая адаптация в Sil'mir.
